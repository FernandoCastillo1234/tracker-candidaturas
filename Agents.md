# Registro de uso de IA (v1.0)

Durante el desarrollo de esta entrega le hemos preguntado a herramientas de IA (ChatGPT / Gemini) varias dudas puntuales sobre Java, errores de Git y diseño en Figma:

**1. Sobre leer el array args en Java:**
> "Hola, si ejecuto mi programa Java poniendo `--estado pendiente`, ¿cómo puedo hacer un bucle for en el main para sacar la palabra 'pendiente' sin usar Scanner?"

**2. Sobre guardar en el archivo txt:**
> "¿Qué código básico de Java sirve para escribir una línea nueva al final de un archivo txt sin que se borre lo que ya estaba guardado antes?"

**3. Sobre ignorar mayúsculas y minúsculas:**
> "¿Cómo hago en Java para que no importe si el usuario escribe en la terminal 'LISTAR', 'Listar' o 'listar' y el programa lo reconozca igual?"

**4. Sobre saltarse la cabecera al leer el archivo:**
> "Tengo un archivo guardado donde la primera línea son los nombres de las columnas ('id;titulo;empresa...'). ¿Cómo puedo hacer un if sencillo en Java para saltarme esa primera línea y leer solo los datos?"

**5. Sobre resolver bloqueos en Git:**
> "Me sale un error en la terminal de 'Your local changes would be overwritten by merge' al hacer git pull. ¿Cómo puedo apartar mis cambios un momento para poder descargar lo de mi compañero sin romper nada?"

**6. Sobre diseño e interactividad en Figma:**
> "¿Me dices 4 colores en hexadecimal que queden bien en Figma para los estados (pendiente, aceptado, rechazado, entrevista) y cómo hago para que un botón cambie de pantalla al hacer clic?"
